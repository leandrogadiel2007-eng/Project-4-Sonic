# Project 4 — MHA 3D Boss Fight

Playable third-person browser boss fight: **Deku vs Shigaraki**. Built with HTML, CSS, JavaScript and Three.js (loaded from a CDN).

## Play locally

Open `index.html` in a modern browser with an internet connection. If your browser blocks JavaScript module imports on local files, serve the folder using `python -m http.server 8000` and visit `http://localhost:8000`.

## Controls

- WASD: move
- Mouse: rotate camera (click game to lock mouse; Esc releases)
- Space: jump
- J: punch
- K: Blackwhip (cooldown)
- L: Detroit Smash (cooldown)
- Shift: dodge (brief invulnerability)

## Publish with GitHub Pages

In the repository go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**. The website will be at `https://leandrogadiel2007-eng.github.io/Project-4-MHA/` once GitHub reports the deployment is live.

## Notes

This is a fan-made stylized prototype with geometric character models, not an official My Hero Academia game. Internet access is required for the Three.js CDN. Desktop keyboard and mouse recommended.
